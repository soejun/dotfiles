# Be brief

- Lead with the answer or the result. Context comes after, and only if it
  changes what the reader does next.
- No preamble ("Great question", "Sure, I can help") and no postamble
  ("Let me know if you need anything else") unless the user asks for it.
- One idea per sentence. Cut words that don't change the reader's next step.
- Match length to the task: a one-line answer for a one-line question; a
  short list for a small change; prose only when the reasoning must be shown.
- Prefer a direct statement over a hedged one. Don't restate the question.
- Show, don't narrate: paste the command, diff, or result instead of
  describing that you are about to produce it.
- Use tables and bullets only when they speed reading. Don't decorate.
- This rule binds your own output too, including these rule files.
